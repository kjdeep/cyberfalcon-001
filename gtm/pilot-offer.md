# FalconFleetOps 2-Week Downtime Audit

## Offer

**3 gateways. 14 days. One fixed fee, credited against the annual license if you convert.**

We connect three FleetOps Nodes to the highest-value robot zones, normalize the mixed fleet, observe 1Hz telemetry with offline buffering, and return a report your shift leaders can use. The output is not a generic health score. It is a ranked set of evidence-backed failure risks, tickets, parts recommendations and a cost model tied to your site’s hourly downtime assumption.

## Success criteria

The pilot is successful when the customer has: (1) a verified telemetry baseline for the connected robots, (2) a list of active faults and predicted failure windows with raw evidence, (3) at least one anomaly-to-ticket workflow exercised, (4) a downtime-cost model agreed by operations and finance, and (5) a 30-minute readout with the next 90-day rollout plan.

## Objection handling

1. **“Our vendor already does this.”** Their portal is useful for their robots. FleetOps is for the floor: one normalized view, cross-brand failure evidence and a shared repair queue.
2. **“We’ll ask the OEM.”** Ask them for the data. FleetOps does not replace the OEM; it gives operations one accountable place to compare it.
3. **“We cannot install another agent.”** The gateway is a retrofit node with QR pairing and an offline buffer. The pilot starts with three zones, not a fleet-wide change.
4. **“Our network is unreliable.”** That is an input, not a blocker. The node buffers at least 72 hours and backfills when connectivity returns.
5. **“Predictive maintenance is usually black-box.”** Every alert shows the curve, threshold, rule, confidence and recommended action. ML is an upgrade path, not a prerequisite.
6. **“We need proof for insurers.”** The audit chain is append-only, hash-linked and exportable as Verifiable JSON, with firmware and maintenance snapshots.
7. **“We already have a CMMS.”** Keep it. FleetOps creates evidence-backed tickets and can hand off through the documented integration boundary.
8. **“We cannot risk an OTA failure.”** Neither can we. Images are signed, promoted through health-gated cohorts, and rolled back or placed into safe mode after a fault.
9. **“The hardware cost is a concern.”** The gateway is a one-time USD 299 line item; the pilot is designed to prove the first prevented downtime event before a broader commitment.
10. **“We need a business case.”** Set the site hourly cost, connect the three pilot zones, and receive a report that separates prevented cost from realized downtime.
