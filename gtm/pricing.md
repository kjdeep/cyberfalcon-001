# FalconFleetOps pricing

| Tier | Monthly price | Product scope |
| --- | ---: | --- |
| Pilot | Free for 30 days | 3 robots, Observe, Tickets, onboarding review |
| Floor | USD 40 / robot / month | Observe + Tickets |
| Predict | USD 60 / robot / month | Floor + Predict |
| Assurance | USD 80 / robot / month | Predict + Prove + RaaS portal |
| FleetOps Node | USD 299 one-time | Gateway hardware, factory pairing and offline buffer |
| Parts take-rate | 10% | Applied to parts marketplace orders |
